# Haseeb Raza — Portfolio Website

Full-stack MERN portfolio with admin panel.

## Quick Start

### Backend
```bash
cd server
npm install
# Edit .env with your MongoDB URI, Gmail App Password, Cloudinary keys
npm run seed   # seed initial data
npm run dev
```

### Frontend
```bash
cd client
npm install
npm run dev
```

Visit http://localhost:3000 — Admin panel at /admin/login

## Deployment
- Frontend: Vercel
- Backend: Render.com
- Database: MongoDB Atlas
- Images: Cloudinary
